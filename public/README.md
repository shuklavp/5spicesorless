# Public Static Assets Directory

Any image or file you place in this `public` folder is automatically served by Cloudflare at the root of your website:

- **Logo**: Save your logo as `public/logo.png` (or `public/logo.svg`). The navbar will automatically display it.
- **Profile Sketch or Portrait**: Save your sketch or photo as `public/profile-sketch.png`. The About / Profile section will automatically feature it.
- **Essay Sketches & Drawings**: Save your drawings in `public/sketches/` (e.g. `public/sketches/drawing-1.png`). In your essays or components, you can link to them as `/sketches/drawing-1.png`.
